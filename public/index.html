Dashboard guide

CarrierFlex VB Cancel + BST activity

Getting started

Run npm start to launch the dashboard with the cancellation listener and BST poller, or use npm run dashboard to run only the dashboard. Locally, open http://127.0.0.1:3100. It reads the cancellation and BST logs and refreshes every 15 seconds.

Finding activity

Search by PO, ASN, VB reference, filename, or detail. Use the flow and result menus to narrow the activity list. Each row shows its timestamp, flow, PO reference(s), ASN, VB reference, result, and output or skip detail.

Result meanings

  • Cancel submitted: the VBKREQ reached the configured SFTP destination; this does not confirm E2open processed the cancellation.
  • BST submitted: the BST file reached the configured E2open SFTP destination.
  • Skipped: no cancellation was sent, including when another same-day outbound 856 uses the same VB reference for a different ASN.
  • Failed: processing or upload logged an error. Saved locally means output was written without SFTP.

PO and ASN data

Cancellation PO references are associated with each ASN by the Databricks query. Related ASNs appear on skipped shared-booking rows. BST PO references appear only when supplied in a recognized carrier-file column; historical entries without PO data are not backfilled.

Log sources

Activity comes from state/cancel-log.json and state/bst-log.json. The dashboard uses the platform-provided PORT when available. Locally, it defaults to port 3100 and is available only on this machine.
